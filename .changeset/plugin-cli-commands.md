Add the `/harnessforce:status`, `/harnessforce:import`, `/harnessforce:usage-limits`, `/harnessforce:run` and `/harnessforce:help` commands, which wrap the `harnessforce` CLI inside a Claude Code session. `/harnessforce:status` summarizes `harnessforce top --once --json`; `/harnessforce:usage-limits` only shows the state and leaves turning sharing on or off to you.
